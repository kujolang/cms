# CMS 1.2.1

This maintenance release updates the supported Node.js release lines for JavaScript clients and verification tooling, avoids release-gate port collisions, and fixes worker output cleanup races. API envelopes, database schema, environment settings, and portable extension contracts remain unchanged from 1.2.0. The CMS Ability pack and pinned Ability runtime remain independently versioned at 1.0.1.

Use Node 22.23.4+, 24.22.1+, or 26.12.1+ within the supported release lines. Install CMS through `kennel add cms`, or clone tag `v1.2.1` and run `kennel install`. Kennel excludes `.env.*`; use the tagged `.env.example` when configuring a registry installation. Existing deployment identity, ingress, storage, backup and monitoring requirements still apply.

Verification on Kujo 1.8.2 and Node 26.12.1: the full `CMS_GATE_PERF_RUNS=10 bash scripts/run-release-gate.sh` passed, including contracts, JavaScript/PHP clients, security, tenant boundaries, queue processing, graceful restart, operational load and performance budgets. The separate startup compatibility check passed. CMS Example's complete `npm run check` passed against this backend with zero audited vulnerabilities.
